# Qu'est-ce qui pousse un client à annuler sa réservation d'hôtel ?

Analyse de 119 390 réservations (dataset Hotel Booking Demand, Kaggle) pour identifier les facteurs d'annulation et proposer des recommandations à un hôtel.

**Principaux résultats**
- 37 % des réservations sont annulées
- Facteur n°1 : les réservations non remboursables des agences et groupes (annulées à 99,4 %)
- Les clients qui font des demandes spéciales annulent deux fois moins
- Le prix et la durée du séjour n'ont aucun lien avec l'annulation

**Outils** : Python, pandas, matplotlib, SciPy (Chi-2, V de Cramer, ANOVA)

L'analyse complète est dans `projet_hotel_final.ipynb`.
